ANS 1.  
Web development is mainly divided into frontend, backend and full-stack development.
Frontend development is the part of a website that users can see and use. It includes the buttons, menus, text, images and overall design. HTML, CSS and JavaScript are mainly used for frontend development.
Example: On Amazon, the product page, search bar and add-to-cart button are part of the frontend.
Backend development works behind the website. It handles things like login, data processing, business logic and communication with the database. Languages like Java, Python, PHP and JavaScript (Node.js) can be used for backend development.
Example: When we log in to Amazon, the backend checks our login details and gets the required information from the database.
Full-stack development means working with both frontend and backend. A full-stack developer can create the user interface as well as the server-side part of a website.
Example: A developer creating an online food-ordering website, including its webpage, backend and database connection, is doing full-stack development.

ANS 3.
When we enter a website address in a browser, the following steps normally happen:
1.	The user enters a URL such as https://example.com.
2.	DNS finds the IP address of the website's server.
3.	The browser connects to the server.
4.	The browser sends an HTTP/HTTPS request.
5.	The server processes the request.
6.	The server sends files such as HTML, CSS and JavaScript back to the browser.
7.	The browser reads these files and displays the webpage.
In simple form:
URL
 ↓
DNS
 ↓
Web Server
 ↓
HTTP Request
 ↓

 ↓
HTML + CSS + JavaScript
 ↓
Browser
 ↓
Web Page

ANS 6.
Frontend Developer
A frontend developer creates the part of the website that users interact with. They work mainly with HTML, CSS and JavaScript.
Their work includes:
●	Designing webpages
●	Making websites responsive
●	Adding user interactions
●	Connecting the frontend with APIs
Backend Developer
A backend developer works on the server side of an application.
Their work includes:
●	Creating server-side logic
●	Developing APIs
●	Handling login and authentication
●	Connecting applications to databases
●	Processing user requests
Database Administrator
A Database Administrator, or DBA, manages the database.
Their responsibilities include:
●	Creating and managing databases
●	Managing users and permissions
●	Taking backups
●	Maintaining database security
●	Monitoring database performance
All three roles are important for building a complete web application.

A static website has mostly fixed content. The same content is generally shown to every visitor unless the files are manually changed.
Example: A simple personal portfolio website.
A dynamic website can change its content depending on the user, database or other information.
Example: An e-commerce website showing different products, prices and orders.

ANS 9.
A web browser is software used to open and display websites. Different browsers use different rendering engines.
Browser	Rendering Engine
Google Chrome	Blink
Microsoft Edge	Blink
Mozilla Firefox	Gecko
Apple Safari	WebKit
Opera	Blink
Rendering engines are responsible for interpreting HTML and CSS and displaying the webpage.
Because different engines have different implementations, a website can sometimes look or behave slightly differently in different browsers. This is why developers test their websites on multiple browsers.
JavaScript also uses separate JavaScript engines. For example, Chrome uses V8, while Firefox uses SpiderMonkey.
